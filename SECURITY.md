# Security policy

## Development status

Sovereign Stack OS is currently a developer preview. No release before version 1.0 should be treated as suitable for protecting high-value keys or irreplaceable data.

## Reporting vulnerabilities

Until a dedicated private reporting channel is established, do not publish exploit details in a public issue. Open an issue containing only a short request for a private contact path. Never include seed phrases, private keys, passwords, access tokens, personal data, or production logs.

## Supported versions

Only the newest development revision is currently supported. A formal security-support table will be introduced with the first signed release.

## Trust model

Generated images inherit substantial code from Debian and upstream projects. Project-specific security work focuses on build transparency, conservative defaults, artifact verification, and minimizing additional trust roots. See [docs/THREAT_MODEL.md](docs/THREAT_MODEL.md).
